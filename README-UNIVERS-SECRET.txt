PLANET GEEK — UNIVERS SECRET

Ajouts : page univers-secret.html, coffre quotidien, 20 fragments, succès, mode anomalie visuel, sons générés après activation utilisateur et cinq mini-jeux.
La progression utilise localStorage dans le navigateur courant. Elle ne synchronise pas automatiquement entre appareils et peut être perdue si les données du site sont effacées.
Installation : publier tout le dossier, en conservant les fichiers déjà existants.
Vérification : archive testée, liens locaux contrôlés, script de la nouvelle page contrôlé par Node.js.
Limite : aucune session de test automatisée dans un vrai navigateur n’a été effectuée.
