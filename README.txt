PLANET GEEK — VOL UN ŒUF : PACK DE MISE À JOUR

Fichier : vol-un-oeuf.html

Pour tester :
1. Décompresse le ZIP.
2. Ouvre vol-un-oeuf.html dans un navigateur récent.
3. Une connexion Internet est nécessaire pour charger Three.js depuis unpkg.com.
4. Les sauvegardes sont stockées dans le navigateur (localStorage).

Commandes :
- ZQSD ou WASD / flèches : déplacement
- Espace : ramasser un œuf proche
- E : utiliser un portail proche

Contenu inclus dans cette version :
- Décor 3D et base à plusieurs étages (améliorable)
- Œufs de plusieurs raretés, collecte et éclosion
- Boutique de vitesse, base et sécurité
- Fusion de 3 créatures de même rareté
- Compagnon, quêtes, événements temporisés et rebirth
- Portails entre zones
- Voleurs IA qui ramassent des œufs
- Sauvegarde locale

IMPORTANT : ce ZIP contient une version autonome de Vol un Œuf à tester. Ce n’est pas une fusion automatique dans les fichiers existants de Planet Geek. Pour l’intégrer au site sans remplacer tes pages existantes, ajoute ce fichier au dépôt puis crée un lien vers vol-un-oeuf.html depuis la page du jeu. Le vrai multijoueur en ligne n’est pas inclus : il nécessite un serveur partagé. Les voleurs sont des IA locales, pas des joueurs réels.
