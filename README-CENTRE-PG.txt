PLANET GEEK — MISE À JOUR CENTRE PG

Nouveautés :
- Centre PG : tableau de bord de progression, XP, pièces, missions quotidiennes, boutique cosmétique, casier et records personnels.
- Défis partageables par message (pas de faux multijoueur ni de classement en ligne simulé).
- Accès Centre PG depuis l'accueil et raccourci sur les pages principales.
- Styles responsive pour PC et téléphone.

Installation : extraire l'archive puis envoyer le contenu du dossier planet-geek2.0-main dans le dépôt GitHub Pages en conservant les fichiers existants. Garder une copie de sauvegarde avant remplacement.

Limites honnêtes : les données sont locales à chaque navigateur. Les classements synchronisés entre joueurs et les sauvegardes PC/iPhone nécessitent un backend et des comptes. Les missions de ce Centre PG sont indépendantes des éventuels objectifs existants.
