# Planet Geek — version multipage

Site statique de mini-jeux pour GitHub Pages.

## Pages
- `index.html` : accueil
- `jeux.html` : catalogue des jeux
- `profil.html` : profil et progression
- `boutique.html` : boutique
- `casier.html` : profil et éléments du casier
- `pass.html` : pass de saison
- `arene.html` : arène
- `stats.html` : statistiques et défis

## Mise en ligne
Téléverse tous les fichiers du ZIP dans le dépôt GitHub Pages, en conservant `style.css`, `app.js`, `games.js`, les PDF et les pages déjà présentes. Fais un commit, attends la publication puis recharge avec Ctrl+F5.

Les pages gardent le même design et les mêmes scripts pour préserver les jeux et la progression locale. Les données restent stockées dans le navigateur : il n'y a pas de compte serveur ni de multijoueur en ligne.
